# OS Synchronization Assignment

## Overview

This project demonstrates process synchronization using semaphores and monitors in Java. It covers the Readers-Writers problem and the Dining Philosophers problem.

## Programs

1. Readers-Writers using semaphores
2. Readers-Writers using monitors
3. Dining Philosophers using semaphores (4 philosophers)
4. Dining Philosophers using monitors (4 philosophers)

## Technologies Used

* Java
* Semaphores
* Java synchronization (`synchronized`, `wait()`, and `notifyAll()`)
* HTML, CSS, and JavaScript for execution simulations

## Project Structure

* `src/` — Java source files
* `generated_html/` — HTML simulations generated by the programs
* `screenshots/` — screenshots of program execution and HTML simulations
* `report/` — assignment report and related documents
* `ai_prompts/` — record of AI prompts used during development
* `REFERENCES.md` — references used in the assignment

## How to Compile and Run

Open a terminal in the folder containing the required Java source file.

For the Readers-Writers semaphore implementation:

```bash
javac ReadersWritersSemaphore.java
java ReadersWritersSemaphore
```

For the Readers-Writers monitor implementation:

```bash
javac ReadersWritersMonitor.java
java ReadersWritersMonitor
```

For the Dining Philosophers implementations, use the corresponding Java filenames and the run instructions documented with those source files.

The programs generate HTML simulations based on execution events. Open the generated HTML files in a web browser to view the simulations.

## Synchronization Concepts

* Mutual exclusion
* Critical sections
* Semaphore acquire and release
* Monitor synchronization
* Waiting and notification
* Deadlock and starvation considerations
